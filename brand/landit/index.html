(index of all assets: https://asset.landit.com.au/llms.txt). Use the published asset URLs; don't redraw logos or icons.

Which format to use

Web app (React etc.)

Logos: SVG. Icons: inline SVG (<name>.svg, import as components) coloured with CSS color.

Landing pages

Logos: SVG. Icons: inline SVG, or the fixed-colour SVG in an <img>. Favicon: the favicon/ set.

EDM (email)

Logos: PNG @2x shown at half size. Icons: PNG. Email clients don't render SVG reliably. Absolute URLs only.

Print

Logos and icons: SVG (vector, any size), or ask for the PDF/EPS masters. Never the web PNGs.

Docs and slides

PNG @2x (or SVG where supported). Start decks from the deck template.

Colour

Default: white surface, navy text, red accents. Impact (headers, banners): navy surface, white text, red mark. Red surfaces take white only.

Logo

Clear space at least 24 px. Full logo at least 120 px wide on screen (30 mm in print); smaller than that, use the mark alone (at least 16 px). Use PNG in email.
